## 86HB68-401A步进电机
![[Pasted image 20260406182745.png]]

|参数项|数值|含义|
|---|---|---|
|**型号**|86HB68-401A|86 型两相步进电机，机身长 68mm，电流 4A|
|**相数 / 步距角**|2-PHASE/1.8°|两相四线制，每步转 1.8°，转一圈需要 200 步（360°/1.8°=200）|

|**保持扭矩**|3.04N·m|86 步进电机的标准大扭矩，适合传送带、负载驱动|
|**绕组定义**|A + 黑、A - 绿；B + 红、B - 蓝|两相绕组的接线定义，接驱动器时必须按相序接|

## DMA860H得轩电机驱动板

| 参数项  | 核心说明                                               |
| ---- | -------------------------------------------------- |
| 供电范围 | DC 24~100V / AC 18~80V，推荐 DC 24~48V（安全、扭矩充足）       |
| 电流调节 | SW1/SW2/SW3 拨码开关设置，SW4 控制半流 / 全流（on = 全流，off = 半流） |
| 细分调节 | SW5/SW6/SW7/SW8 拨码开关设置，决定每圈所需脉冲数                   |
| 信号接口 | DIR（方向）、PUL（脉冲）、ENA（使能），支持共阳极 / 共阴极接法              |
| 适配电机 | 两相 4 线 / 6 线 / 8 线步进电机，完美匹配 86HB68-401A            |
### Setting：
拨码规则：**ON = 下拨 = 1，OFF = 上拨 = 0**
SW1-SW3：输出电流设置(根据**电动机额定电流**选择)
SW4：半流/全流选择(静止时是否降流)
- W4=ON（全流）：运行 / 静止均为额定电流，**扭矩最大**，但静止发热大，适用于**==传送带/连续运行==保证扭矩**的场合
- SW4=OFF（半流）：无脉冲约 500ms 后，电流自动降为额定的 50%，静止发热减半，不影响运行扭矩，适合用于==**间歇/待机多**==的省电降温场合
SW5-SW8：细分/每圈脉冲数设置(决定转速与平稳性)

全流模式；细分400脉冲/圈

#### Setting关键知识点
##### 电流匹配原则

- 必须**==驱动电流  ≤ 电机额定电流==**，严禁超流（烧电机 / 驱动）
- 86 电机建议 **全流运行**，保证扭矩

##### 2. 转速公式（必记）
转速(RPM)=每圈脉冲数脉冲频率(Hz)×60​
- 例：400 脉冲 / 圈，10kHz 脉冲 → 转速 = (10000×60)/400 = **1500 RPM**
##### 3. 细分选择逻辑
- **全速优先**：选 **最低细分（400）**
- **平稳优先**：选 **8/16 细分（1600/3200）**
- **高精度**：选 **32/64 细分（6400/12800）**
##### 4. 拨码操作注意
- **断电设置**：必须在 **断电** 状态下拨码，严禁带电操作
- **确认无误**：上电前再次核对拨码状态，避免设置错误
## 接线
| 驱动板端子       | 接线对象              | 作用                   |
| ----------- | ----------------- | -------------------- |
| DIR+ /DIR-  | 接地/GPIO           | 控制旋转方向               |
| PUL+ / PUL- | 接地/GPIO           | 提供脉冲信号               |
| ENA+/ENA-   | 悬空 / STM32 引脚（可选） | 使能信号，默认悬空 = 使能，可用于急停 |
| A+ / A-     | 电机 A 相（黑 / 绿）     | 电机绕组 A 相供电           |
| B+ / B-     | 电机 B 相（红 / 蓝）     | 电机绕组 B 相供电           |
| 两个AC        | 24~48V 直流电源(开关电源) | 驱动板主供电，注意正负极         |

### 接线的方法会影响程序编写
| 接法  | 接线特点                     | 有效电平  | GPIO 模式要求      |
| --- | ------------------------ | ----- | -------------- |
| 共阳极 | 信号 + 接电源，信号 - 接 MCU      | 低电平有效 | 推挽输出（Out_PP）   |
| 共阴极 | 信号 - 接 GND，信号 + 接 MCU    | 高电平有效 | 推挽输出（Out_PP）   |
| 共性  | 都需要明确高低电平，**==绝对不能悬空==** |       | 必须推挽输出，保证强驱动能力 |

### 共阳极接法
![[Pasted image 20260406203435.png]]
共阳极接法中，DIR+和PUL+都接到单片机的3.3V/5V上，相当于高电平，那么当DIR-为低电平时有效，DIR-为高电平无效，PUL为脉冲，由PUL-进行控制
#### 为何引脚需要选择推挽输出模式
- 需要由引脚输出信号带动进行工作，所以在4个输出状态下进行选择
- 由于驱动需要==强上拉+强下拉==，需要选择推挽输出(OUT_PP)模式，因为在推挽输出模式下Nmos和Pmos都会分别导通，非常安全
- 开漏输出(OUT_OD)情况下上拉是悬空的，会影响电流效果，严重影响功能
- 复用开漏输出(AF_OD)和复用推挽输出(AF_PP)是片上外设控制，在此不能用

## 控制传送带
传送带暂时只需要实现单向定速启停运行，所以暂时不用用到PWM波形进行一个速度的控制
Conveyor1.c
```c
#include "stm32f10x.h"                  // Device header
#include "Delay.h"

//DIR1方向- 接PA5
#define DIR_PIN1 GPIO_Pin_5
#define DIR_PORT1 GPIOA
#define DIR_CLK1 RCC_APB2Periph_GPIOA

//PUL1方向- 接PA6
#define PUL_PIN1 GPIO_Pin_6
#define PUL_PORT1 GPIOA
#define PUL_CLK1 RCC_APB2Periph_GPIOA

void Conveyor1_Init(void)
{
	/*开启时钟*/
	RCC_APB2PeriphClockCmd(DIR_CLK1|PUL_CLK1, ENABLE);			//开启GPIOA的时钟
	/*GPIO初始化*/
	//DIR-
	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode =  GPIO_Mode_Out_PP;
	GPIO_InitStructure.GPIO_Pin = DIR_PIN1;
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOA, &GPIO_InitStructure);							
	//将PA2引脚初始化为复用推挽输出	
	//受外设控制的引脚，均需要配置为复用模式
	//PUL-
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
	GPIO_InitStructure.GPIO_Pin = PUL_PIN1;
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOA, &GPIO_InitStructure);	
	
	//DIR与PUL都置高电平无效状态
	GPIO_SetBits(DIR_PORT1, DIR_PIN1);
	GPIO_SetBits(PUL_PORT1, PUL_PIN1);
}
void Conveyor1_Start(void)
{
	//将DIR置低电平，有效状态，根据脉冲开始运动
	GPIO_ResetBits(DIR_PORT1, DIR_PIN1);
	//PUL脉冲一直在0/1输出
	while(1)
	{
		GPIO_ResetBits(PUL_PORT1, PUL_PIN1);
		Delay_ms(1);//改速度改这个，改小
		GPIO_SetBits(PUL_PORT1, PUL_PIN1);
		Delay_ms(1);//改速度改这个，改小
	}
}
void Conveyor1_Stop(void)
{
	//将DIR置高电平，无效状态，停止
	GPIO_SetBits(DIR_PORT1, DIR_PIN1);
}
```
