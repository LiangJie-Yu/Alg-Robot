## 名词讲解
### PLL锁环
芯片**内置硬件倍频电路**，独立运行、不占用 CPU 资源
作用：把低频基准时钟倍频为高频时钟，兼顾「基准精度」与「运行速度」。
### 总线架构
STM32 采用==**多级总线分层分配**时钟==，不同外设挂载在不同总线上，总线有最大时钟限制，必须分频使用：
- **AHB 总线**：高速主控总线，连接内核、内存、DMA、FSMC 等；F103 最大 72MHz。
- **APB1 总线**：低速外设总线，挂载串口 2/3、I2C、定时器 2~4、CAN 等；**最大 36MHz**（硬性限制）。
- **APB2 总线**：高速外设总线，挂载 GPIO、串口 1、SPI1、ADC、外部中断等；**最大 72MHz**。

|时钟源|全称|硬件位置|标准频率|核心特点|
|---|---|---|---|---|
|HSI|内部高速振荡器|芯片**内部**|8MHz|无需外围元件，上电默认启动；精度一般，温漂大|
|HSE|外部高速晶振|芯片**外部**|典型 8MHz（范围 4~16MHz）|需外接晶振 + 起振电容；精度高、稳定性强，工程主流|
|LSI|内部低速振荡器|芯片**内部**|约 40kHz|专供独立看门狗、RTC 低速电路使用，不做系统主时钟|
**系统主时钟只能由 HSI / HSE 二选一，再经过 PLL 倍频后供给内核与总线**。
## 时钟树流程
![[Pasted image 20260526203031.png]]
1. 开启时钟源(HSI内部晶振/HSE外部晶振)
2. 配置PLL倍频(走72MHz必配)
3. 切换系统时钟源选择(HSI/HSE/PLL)
4. 配置AHB，APB1，APB2总线分频
5. 单独开启各个外设时钟(外设默认时钟关闭，必须手动开)
### 关键规则
1. F103 内核**最大主频 72MHz**，严禁超频。
2. APB1 总线时钟 **不能超过 36MHz**，因此当 SYSCLK=72MHz 时，APB1 必须二分频。
3. 所有外设**默认时钟关闭**，必须代码手动开启对应总线外设时钟，外设才能工作。
4. 若某时钟源正在作为**当前系统时钟**，则无法被关闭（如 HSI 正在跑系统，调用关闭函数无效）。
## HSI/HEI使用场景及区别
### 使用HSI内部时钟(无外部晶振)
#### 硬件条件
- 电路板**不焊接外部晶振、起振电容**，仅使用芯片内部电路。
- 适用：简易点灯、IO 测试、临时调试、低功耗简单设备。
- 限制：最高主频 8MHz，**不适合串口、PWM、精密定时、通信类外设**（精度差）。
#### 时钟链路
HSI(8MHz) →可使用PPL倍频→直连系统时钟SYSCLK(8MHz) → 总线分频 → 外设
#### 代码示例：
```c
#include "stm32f10x.h" // HSI内部时钟初始化函数（主频8MHz） 
void HSI_Clock_Init(void) { 
	// 1. 开启内部高速时钟 HSI（硬件使能内部振荡器） 
	RCC_HSICmd(ENABLE); 
	// 2. 等待HSI起振稳定（硬件标志位：HSIRDY=1表示稳定）
	while(RCC_GetFlagStatus(RCC_FLAG_HSIRDY) == RESET); 
	// 3. 关闭PLL（本方案不用倍频，关闭节省功耗） 
	RCC_PLLCmd(DISABLE); 
	// 4. 配置三级总线分频 
	RCC_HCLKConfig(RCC_SYSCLK_Div1);
	 // AHB时钟 = 系统时钟 8MHz 
	 RCC_PCLK1Config(RCC_HCLK_Div2); 
	 // APB1 = 4MHz（满足<36M限制） 
	 RCC_PCLK2Config(RCC_HCLK_Div1); 
	 // APB2 = 8MHz 
	 // 5. 切换系统时钟源为 
	 HSI RCC_SYSCLKConfig(RCC_SYSCLKSource_HSI); 
	 // 等待时钟切换完成 
	 while(RCC_GetSYSCLKSource() != 0x00); 
	 // ========== 外设时钟开启示例 ========== 
	 // APB2总线：开启GPIOA时钟（点灯必备） 
	 RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE); }
```
### 使用HSE外部晶振+PPL倍频(工程主流72MHz)
#### 硬件条件
- 芯片 `OSC_IN`、`OSC_OUT` 引脚外接 **8MHz 无源晶振 + 2 个 20~30pF 起振电容**。
- 适用：正式产品、串口、I2C、PWM、电机、传感器等几乎所有项目。
- 优势：基准时钟精度高，倍频后跑满 72MHz 最大性能。
#### 时钟链路
HSE(8MHz) → 不分频输入PLL → PLL硬件×9倍频 → 72MHz(SYSCLK) → 总线分频 → 外设
计算：8MHz×9=72MHz
#### 代码示例
```c
#include "stm32f10x.h" 
// HSE外部晶振+PLL倍频至72MHz 标准初始化 
void HSE_PLL_72M_Clock_Init(void) { 
// 1. 开启外部高速晶振 
HSE RCC_HSEConfig(RCC_HSE_ON); 
// 等待外部晶振起振稳定 
while(RCC_GetFlagStatus(RCC_FLAG_HSERDY) == RESET); 
// 2. 配置PLL硬件倍频（核心：硬件9倍频） 
// 输入源：HSE不分频；倍频系数：9倍 
RCC_PLLConfig(RCC_PLLSource_HSE_Div1, RCC_PLLMul_9); RCC_PLLCmd(ENABLE); 
// 硬件使能PLL锁相环 
// 等待PLL输出时钟稳定 
while(RCC_GetFlagStatus(RCC_FLAG_PLLRDY) == RESET); 
// 3. 总线分频（72MHz标准配置，严格遵守硬件限制） 
RCC_HCLKConfig(RCC_SYSCLK_Div1); 
// AHB = 72MHz 
RCC_PCLK1Config(RCC_HCLK_Div2); 
// APB1 = 36MHz（达最大允许值） 
RCC_PCLK2Config(RCC_HCLK_Div1); 
// APB2 = 72MHz 
// 4. 切换系统时钟为 PLL输出时钟（72MHz） 
RCC_SYSCLKConfig(RCC_SYSCLKSource_PLLCLK); while(RCC_GetSYSCLKSource() != 0x08); 
// 5. 可选：系统已切换至PLL，关闭闲置HSI，降低功耗 
RCC_HSICmd(DISABLE); 
// ========== 外设时钟开启（区分总线） ========== 
// APB2：GPIO、USART1、SPI1 
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE); RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1, ENABLE); 
// APB1：USART2、I2C、TIM2 
RCC_APB1PeriphClockCmd(RCC_APB1Periph_USART2, ENABLE); RCC_APB1PeriphClockCmd(RCC_APB1Periph_I2C1, ENABLE); }
```
### 对比
| 对比项    | HSI 内部时钟 (8MHz) | HSE+PLL(72MHz) |
| ------ | --------------- | -------------- |
| 硬件电路   | 极简，无外围元件        | 需外接 8M 晶振 + 电容 |
| 主频     | 8MHz（低速）        | 72MHz（满速）      |
| 时钟精度   | 一般，温漂大          | 高，通信 / 定时稳定    |
| 适用场景   | 简单 IO、临时测试      | 正式项目、所有外设      |
| PLL 使用 | 关闭              | 开启（硬件 9 倍频）    |
| 功耗     | 更低              | 偏高             |
## 其他STM32系列芯片时钟体系差异
以 **F0、F4、L4、H7** 为例，对比和 F103 的不同点（原理通用，配置有区别）

### 1. STM32F0 系列（入门低成本）

1. 时钟源：同样保留 HSI/HSE/LSI，但默认 HSI 频率多为 4MHz/8MHz。
2. PLL：倍频档位不同，最大主频多为 48MHz，倍频系数不再固定 9 倍。
3. 总线：依旧 AHB/APB1/APB2，但总线最大时钟限制降低。
4. 代码：标准库函数名逻辑一致，但寄存器、宏定义不同，不能直接移植 F1 代码。

### 2. STM32F4 系列（高性能）

1. 时钟树更复杂：新增 **PLLI2S、PLLSAI** 专用时钟（给音频、摄像头等外设）。
2. 主频：主流 168MHz / 180MHz，外部常用 8MHz/25MHz 晶振，PLL 倍频系数大幅增加。
3. 总线：新增多层总线架构，分频规则更多。
4. 时钟源：部分型号支持 HSI48（专用 48MHz 内部时钟，专供 USB）。

### 3. STM32L 系列（低功耗系列：L1/L4）

1. 核心设计偏向低功耗，时钟分支更多，支持多种低速运行模式。
2. 可动态切换系统时钟频率，运行中降频省电。
3. PLL 默认关闭，仅高性能场景开启，大量使用内部低速时钟。

### 4. STM32H7 系列（高端高性能）

1. 主频极高（400MHz+），时钟树层级极多，多路独立 PLL。
2. 拆分更多独立时钟域，内核、外设、网络、视频可使用不同时钟。
3. 分频、倍频配置逻辑更精细，入门难度高于 F1。
## 不同系列不变点
- 所有系列都是 **RCC 模块统一管理时钟**。
- 架构逻辑：**时钟源 → PLL 倍频 → 总线分频 → 外设**
- 所有外设**默认时钟关闭**，必须手动开启。
- HSI（内部）、HSE（外部）两大基础时钟源命名、功能定义统一。
