## 典型处理：
初级：如：降噪、对比度、锐化
中级：
高级：

|     |                                       |                                       |           |
| --- | ------------------------------------- | ------------------------------------- | --------- |
| 初级  | 这涉及初级操作                               | 以输入输出都是图像为特点                          | 降噪，对比度，锐化 |
| 中级  | 涉及分割，缩减对目标物的描述                        | 以输入为图像，输出是从这些图像中提取特征（边缘轮廓及不同物体的识别）为特点 |           |
| 高级  | 涉及被识别物体的总体理解，以及执行与视觉相关的识别函数（处在连续统一边缘） |                                       |           |
