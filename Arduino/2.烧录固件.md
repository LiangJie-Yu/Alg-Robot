# SSCOM发送AT指令
### 发送端口
#### 在SSCOM里面发送的AT指令
```c

AT+CWMODE=1                              // 设为客户端模式
AT+CWJAP="YU","12345678"                 // 连接手机热点
AT+CIPSTART="UDP","255.255.255.255",8888,8888,2   // 建立 UDP 广播通道
                                    // 255.255.255.255 = 向同一子网内所有设备广播
                                    
AT+CIPSEND=5                             // 准备发送 5 个字节
hello                                    // 输入要发送的数据
```
#### 在SSCOM里面回复的信息
```c
AT
OK

AT+CWMODE=1
OK

AT+CWJAP="YU","12345678"
WIFI CONNECTED 
WIFI GOT IP

OKAT+CIPSTART="UDP","255.255.255.255",8888,8888,2
CONNECT OK AT+CIPSEND=5
OK

hello 
Send OK
```
回复 `SEND OK` 表示数据已广播出去。
### 接收端口
#### 在SSCOM里面发送的AT指令
```c
AT+CWMODE=1                              // 设为客户端模式
AT+CWJAP="YU","12345678"                 // 连接同一个手机热点
AT+CIPSTART="UDP","0.0.0.0",8888,8888,2  // 监听 UDP 端口 8888
                                           // 0.0.0.0 = 接收任意 IP 发来的数据

```
**接收端不需要主动发 `AT+CIPSEND`**，它只需要安静地监听。  
当模块 A 广播数据时，模块 B 的串口会自动打印：
```c
+IPD,5:hello
```
- `+IPD` = 收到的数据包提示
- `5` = 数据长度
- `hello` = 数据内容
